## M2-23 — scheduled lesson release, prerequisite progression, student learning path

Key decisions worth remembering:

- **Migration collision**: `server/migrations/20261018_03_content_release_progress.sql`
  already owns `lesson_completions` (keyed by `lecture_id`, content pipeline). The
  M2-23 migration must therefore create **`course_lesson_completions`** keyed by
  `(student_enrollment_id, lesson_id)` — `CREATE TABLE IF NOT EXISTS
  lesson_completions` would have been a silent no-op and a runtime failure.
- Completion rows are keyed by `students.id` (the principal's
  `student_enrollment_id`), never a user id, so one human at two academies has two
  independent paths.
- `completed_at` is never written by the client or the driver: the insert omits it
  and the column default `CURRENT_TIMESTAMP` is the only instant authority.
- Access decisions use `UTC_TIMESTAMP()` inside the same statement; the pool is
  `timezone:'+02:00'` so all instants are read as `UNIX_TIMESTAMP(col)` epochs and
  rendered with `new Date(epoch*1000).toISOString()`.
- Student router is a separate mount `/api/student-course-access` (never widens the
  owner-only teaching catalog). No tenant/student/enrollment selector is accepted
  from body/query/header.
- Locked lessons carry `description: null` in the DTO itself (withheld in SQL via
  `SUBSTRING(...,1,600)`), so the renderer has nothing to hide.
- Client: `src/features/catalog/student-learning-path.ts` controller replaces
  `StudentContent`'s localStorage student/material selector. Completion is
  single-flight and confirmed by the server; unlocking is only ever learned from a
  bounded follow-up read.
- Teaching editor: the release/prerequisite change detection compares the
  **normalised** instant and the **canonical** prerequisite id, so re-typing the
  same instant is a truthful no-op.
- The prerequisite `<select>` offers only provably earlier active lessons; a create
  with no stated position offers none and says why (the server stores position 0
  and breaks the tie by an id the browser cannot know).
