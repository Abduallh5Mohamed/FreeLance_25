### Lessons worth keeping
- fflate `zipSync`'s flattener accepts ONLY `Uint8Array` members and nested
  plain objects — a **string** member recurses into itself and blows the stack.
  Always encode members to bytes first.
- `unzipSync(data, { filter })` receives `{name, size, originalSize,
  compression}` BEFORE inflation; returning `false` skips inflation entirely —
  this is what makes the audit pass inflate nothing.
- A flat XML token stream silently reinterprets mis-nested markup; an
  open-element stack in the scanner turns well-formedness into a refusal
  (`malformed-xml`). Found by tests, not by review.
- ZIP bounds are read from the archive's own declarations, so a lying archive
  can only make the decoder read LESS than claimed, never more.
