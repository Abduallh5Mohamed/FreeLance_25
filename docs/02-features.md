# نطاق المنتج الكامل

هذه الوثيقة تلخص الوظائف؛ معايير القبول والتبعيات التفصيلية في [17-full-feature-backlog.md](17-full-feature-backlog.md). العلامات M1–M8 هي **ترتيب بناء لا أولوية إسقاط**. لا توجد فئة «خارج النطاق» ضمن الوظائف المدرجة في قرار المنتج.

## Super-Admin

| الوظيفة | بناء | ملاحظة قبول |
|---|---|---|
| دورة حياة tenant: إنشاء/تعليق/استعادة مع سبب | M1/M7 | الانتقال مسجل وغير قابل للإنكار |
| خطط وfeature flags | M7 | تحرير بإذن مستقل، معاينة، تاريخ وتراجع |
| meter: الطلاب النشطون، دقائق المشاهدة، التخزين لكل مدرس | M7 | دفتر usage قابل للتدقيق والتصدير؛ لا يحسب سعرًا تلقائيًا |
| بلاغات ومراجعة محتوى وإجراءات | M7 | queue، قرار/سبب/استئناف وأثر تدقيق |
| تذاكر الدعم | M7 | ملكية، حالة، SLA/تذكير، وصول محدود |
| impersonation | M7 | سبب وموافقة ووقت قصير وإشعار وسجل كامل؛ ممنوع على المال/الهوية الحساسة افتراضيًا |
| audit logs، analytics، MFA | M1/M7 | صلاحيات وتقارير مقاومة للتلاعب؛ MFA إلزامي للإدارة |

## Teacher / Center

إعداد هوية المؤسسة، شعار/لون/RTL/لغة، subdomain ونطاق خاص موثق؛ فروع ومدرسون متعددون؛ مناهج ودورات ووحدات ودروس وملفات وجدولة؛ فتح تدريجي مجدول أو متتابع؛ مدد فصل/شهر؛ فيديو مسجل مع حماية؛ دروس live داخل المنصة مع حضور تلقائي وتسجيل للمكتبة؛ question bank وإعادة استخدام الأسئلة؛ اختبار مؤقت وMCQ آلي وتصحيح يدوي؛ assignment وملفات وتسليم وتصحيح؛ gradebook وتقدم وتقارير؛ مجموعات وجداول وحضور يدوي/آلي؛ استيراد CSV/XLSX؛ coupons؛ certificates؛ announcements؛ تعليقات وQ&A؛ مساعدين وRBAC؛ usage dashboard والتصدير.

## Student

صفحة المدرس واكتشاف الدورة، signup/join، دخول OTP، enrollment، player RTL للجوال مع resume ووضع bandwidth منخفض وتنزيلات عند السماح، اختبارات وواجبات ودرجات وشهادات وإشعارات وQ&A ودعم. لا يثق الطالب بإشارة paid أو tenant من العميل؛ يتم enrollment بالسياسة الخادمية.

## Parent

ربط الطالب بولي الأمر عبر دعوة ورمز تحقق ونطاق قانوني، عرض read-only للتقدم والحضور والدرجات المنشورة فقط، إشعارات وتقارير عبر WhatsApp/SMS بعد opt-in موثق، تغيير وسحب الربط وإدارة أذونات التقرير.

## المتطلبات المشتركة

العربية RTL أولًا والإنجليزية، accessibility، search، notifications in-app/email/WhatsApp/SMS، observability، backups مع restore مجرّب، وتصدير بيانات كامل لكل tenant. التكاملات الخارجية أو قدرات الأجهزة غير المتحقق منها موسومة “Needs verification” في [12](12-evaluation.md).
