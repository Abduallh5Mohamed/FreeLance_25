# UX للمستخدمين الأربعة: RTL أولًا

**القرار الحاكم المحدث:** التسعير تدريجي للمدرس والسنتر؛ فوترة المؤسسة كل 30 يومًا مع حساب مدة فعلية بالثواني وتسوية، لا عمولة على الطلاب؛ محفظة السنتر وحده أو المدرس المستقل؛ خصم الاشتراك من المتاح ومهلة 4 أيام. المرجع [19 — القرارات المعتمدة](19-commercial-registration-wallet-agreement-ar.md)، والموافقة قبل التنفيذ في 18. الوثائق ليست دليل تشغيل.

التفصيل خطوة بخطوة للتسجيل والانضمام والتعلم والتقييم وباقي الأدوار في [18 — رحلات المنتج](18-workflows-and-execution-approval-ar.md). هذه رحلات مستهدفة، ولا تعني أن التطبيق الحالي نفذها.

## مبادئ المنتج

- كل دور يبدأ بمهامه وحالته التالية، لا بلوحة مؤشرات عامة.
- العربية RTL كاملة من document direction إلى الجداول، calendars، player، charts، email templates، focus order، والأرقام/التواريخ. الإنجليزية ليست ترجمة آلية مدفونة.
- طالب وولي أمر mobile-first؛ لوحة المدرس responsive مع keyboard/data-table workflows؛ Super-Admin يوضح الأثر والهوية قبل action حساس.
- access states واضحة: مسجل/معلق/منتهي/مدفوع إن تحقق المزود، محتوى متاح/يفتح بموعد/مقفل، اتصال live، رفع/تصحيح/notification status.
- أفعال حذف/إرسال/استعادة/impersonation تظهر actor/tenant/impact/سبب وتطلب confirmation مناسبًا.

## تدفقات كاملة

### Super-Admin

تسجيل دخول MFA → overview يبين incidents/usage/errors → إنشاء tenant وتحديد owner/branch → تعيين flag/plan capability version → مراجعة usage ledger → معالجة ticket/بلاغ → إذا احتاج دعم impersonation يطلب السبب والمدة ويظهر شريط واضح ويُسجل كل فعل → tenant suspend/restore بسبب → audit/export. عدد تسجيلات الطلاب عند المدرسين أساس الاشتراك؛ العروض والخصومات الخاصة تديرها المنصة وفق 19.

### Teacher/Center

دعوة/دخول → إنشاء مؤسسة/فروع ومدرسين وأدوار → العلامة/لغة/subdomain أو ربط domain عبر DNS proof → import معاينة وتحليل الصفوف → term/group/schedule → course/unit/lesson/files + drip policy → question bank → exam/assignment/gradebook → video/library أو live class schedule → إدارة access/coupons → الحضور وتقارير progress → parent reports/announcement/Q&A → export كامل.

### Student

صفحة عامة من بحث/رابط المدرس → قراءة المنهج والمواعيد → signup/contact verification/OTP → join/enrollment → اختيار فصل/دورة → player resume/low bandwidth/subtitles/download إذا مسموح → timed quiz/exam/assignment → نتيجة/درجة منشورة/شهادة → تعليق/Q&A → in-app/email/text notifications وإدارة تفضيلها.

### Parent

استلام دعوة من المدرس/الطالب المؤهل → verify contact + challenge → اختيار الطفل/صلة/موافقة → لوحة read-only لكل طفل مرتبط → تقدم وحضور ودرجات منشورة → إعداد قناة وتكرار التقرير → preview للمعلومات والقناة ثم opt-in → report delivery status → revoke unlink/stop messages.

## RTL, accessibility, search

direction من locale وليس CSS اتجاه يدوي بكل عنصر؛ icons ذات المعنى تعكس فقط حين يلزم. اختبار Noto Naskh/Noto Sans Arabic font fallback، label/error association، tab order، visible focus، keyboard exam/live controls، reduced motion، contrast، zoom 200%, captions/subtitles/transcripts. Search يحترم tenant/branch/resource visibility من الخادم ويعرض filters ومكان البحث.

## التحقق

اختبروا إكمال كل تدفق بأبعاد 360px وtablet/desktop، لوحة مفاتيح وقارئ شاشة، اتصال بطيء وانقطاع، انتهاء الجلسة، بيانات طويلة بالعربية/الإنجليزية، role/tenant switch، zero/error/loading/conflict states. قيسوا usability task completion لا انطباع الواجهة فقط. قواعد الأداء/accessibility في [17](17-full-feature-backlog.md).

## شاشات مالية لازمة
checkout يوضح سعر المدرس/السنتر والخصم والرسوم وموافقة الخصم والتجديد؛ المحفظة pending/available/reserved؛ فاتورة مقدم وتسوية ودين/دائن؛ طلب فرق ومهلة96ساعة وحالة القيود؛ طلب سحب ووسيلة تحقق ومراجعة؛ استرداد مع reason/funding/provider state. التدفقات التفصيلية المحدثة في18 و19؛ جمهور كل المحتوى وليس الفيديو فقط.

## ضبط الحساب والمحفظة والحماية

19 يحدد فترات الأحداث UTC والثواني بدل تقريب يوم كامل، وفصل receivable وmerchant_wallet وsubscription_credit، وأول فاتورة الأساسي دون عدد متوقع. الحجز القائم لا يستخدم ثانية؛ دائن الاشتراك يخصم فواتيره وليس سحبًا نقديًا. الفترات المستقبلية المؤكدة المدفوعة محمية عند تقييد المؤسسة؛ المهلة الدراسية لها نهاية إلزامية، والمحتوى والنطاق داخل السنتر لا ينقلان بمجرد خروج المدرس. تحقق هذه الحدود في F1 قبل تشغيل المال، ولا تعتبرها منفذة من تحديث الوثيقة.
