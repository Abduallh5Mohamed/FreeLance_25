# قائمة التنفيذ الحالية لاستراتيجية البيزنس

تحديث: **6 نوفمبر 2026 — BUILD-20**. المرجع الحاكم: [الخطة 22](../22-business-strategy-integration-ar.md). هذه قائمة استكمال للرحلات، وليست ادعاءً بغياب الوحدات الأساسية الموجودة في النظام أو قبولًا إنتاجيًا. طلب المالك هو الاستمرار محليًا مع حفظ التغييرات القائمة، دون Git/GitHub أو تشغيل خارجي غير مأذون به.

| الرحلة | الحالة ضمن الاستراتيجية | العمل المتبقي |
|---|---|---|
| J00 — قياس القيمة | سجلات أدلة محلية موجودة؛ القياس الميداني لم يكتمل | خط أساس لوقت المهمة وتكلفتها، ثم مقارنة النتيجة الصحيحة بعد الاستخدام |
| J01 — تشغيل مجموعة | جزئية: إرشاد الاستيراد وتحسيناته | رحلة إعداد المجموعة والأدوار والحسابات المنفصلة، وتدريب مستخدم بديل |
| J02 — حزمة الحصة | جزئية: ربط مواد متعددة وإدارتها، وخادم وواجهة إعداد مراجع الفيديو الصريحة | ربط الواجب والكويز والإعلان، القالب والتوقيت والجمهور ومعاينة النشر؛ تشغيل الطالب ضمن J03 |
| J03 — تجربة وتسليم موثوقان | جزئية: PDF مشروط؛ بيانات فيديو مخولة وجلسة catalog دائمة السياق وتجديد وفحص عند تسليم الوسائط منفذة محليًا | واجهة تشغيل الطالب وحالات الموافقة وعدم الجاهزية؛ قبول المخطط والوسائط والأداء فعليًا، ثم العينة والأجهزة وسياسة الانقطاع |
| J04 — خدمة تصل لمسؤولها | جزئية: تفاصيل ورسائل موثوقة، سياق درس، ملاحظات داخلية، تكليف/تحويل وقائمة «المسند لي» بواجهة فعلية | سياسة متابعة التأخير؛ ثم عقد هوية وصلاحيات موظفي السناتر وسياقات الطلب الأخرى؛ قبول المخطط والفهرس الفعلي |
| J05 — تحضير المدرس | لم تكتمل الرحلة ضمن الاستراتيجية | ملخص بمراجع مخولة من البيانات المتاحة، وقواعد بسيطة واختبار فائدة |
| J06 — الأسرة والأجندة | لم تكتمل الرحلة ضمن الاستراتيجية | ملخص وخطوة متابعة وأجندة أبناء مخولة وتفضيلات وقنوات حقيقية عند اعتمادها |
| J07 — العودة بعد الغياب | لم تكتمل الرحلة ضمن الاستراتيجية | خطة رجوع صغيرة يراجعها المدرس، دون فك الأقفال أو توسيع الاشتراك |
| J08 — التصحيح بالسؤال | لم تكتمل الرحلة ضمن الاستراتيجية؛ توجد وحدات تقييم أساسية | استكمال تكليف المصحح والمعيار والاختصارات ومراجعة أثر إعادة التصحيح وسجله |
| J09 — الكنترول الورقي | توسع اختياري مشروط | تجربة جدوى ودقة لنموذج ثابت، قبل أي وعد بالقراءة أو النشر الآلي |
| J10 — الموسم الجديد | لم تكتمل الرحلة ضمن الاستراتيجية | معاينة إعادة الاستخدام وفصل بيانات وتاريخ الموسم السابق |

## الخطوة التالية

**استكمال J03 بواجهة تشغيل الطالب للفيديو المرتبط بالدرس**: واجهة المالك نُفذت في BUILD-18، والتحقق وقراءة الطالب في BUILD-19، وربط الجلسة والتجديد وتسليم manifest/segment/key والتحقق أثناء heartbeat في BUILD-20. التالي ربط المشغل الفعلي بطلب catalog الصريح، مع حالات الموافقة وعدم الجاهزية وإلغاء الوصول وحماية تغيّر الجلسة؛ لا رجوع لطلب عام عند الرفض. metadata ما زالت تصف التشغيل بأنه unconfigured حتى هذه الخطوة. مخطط السياق الجديد ملف غير مطبق، والاختبارات المحلية لا تثبت تشغيل مزود حقيقي أو أداءه. نتيجة دفعة الفيديو الموسعة بها اختبار محاضرات مدفوعة فاشل موضح في الدليل، فلا تعتبر المشروع كله ناجح الاختبارات. التقدم الجديد منفصل عن القديم؛ إصدار جلسة أو مشاهدة الفيديو لا يكمل الدرس تلقائيًا. بقية الرحلات والبوابات الخارجية تظل كما في الجدول.

بعد الجزء التشغيلي القريب من J04، تُستكمل حزمة الحصة وتجربة الطالب J02/J03، ثم تحضير المدرس والعودة من الغياب وملخص الأسرة حسب تبعيات الخطة. التصحيح والموسم لهما عقودهما؛ OMR يبقى اختياريًا. لا تُضاف دفعات صغيرة بلا أثر على رحلة مستخدم محددة.

## بوابات التشغيل المنفصلة

- ملفات migrations ليست مطبقة؛ تطبيقها وفحصها على بيئة فعلية يحتاج تفويض الإجراء الخارجي المحدد.
- التخزين والفحص والفيديو والإرسال والدفع لا تُفعّل بمزودين حقيقيين ضمن التنفيذ المحلي.
- القبول يتطلب تحققًا فعليًا من الصلاحيات والمخطط والتزامن والتسليم، وقياس حمل/استعلامات/موارد؛ نجاح الاختبارات المصطنعة لا يثبت ذلك.
- تبقى عدة محتويات لكل درس، وسجلا تقدم catalog والمحتوى القديم منفصلين مؤقتًا. الشهادات خارج النطاق المعتمد.
