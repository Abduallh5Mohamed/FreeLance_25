# BUILD-47 — استرجاع دورة مكتبة القوالب كاملة بعد إعادة التحميل

أُنجزت دفعة J02 التالية لـBUILD-46: إنشاء القالب وإضافة مراجعة وأرشفته، مع استرجاع نتيجة العملية بعد انقطاع الرد وإعادة فتح المقرر. تطبيق القالب كان قد استُكمل في BUILD-45؛ هذه الدفعة تغلق فجوة استرجاع عمليات المكتبة نفسها، ولا تدعي إغلاق رحلة الحصة بكل مصادرها.

## السلوك والعمارة

- `src/features/catalog/lesson-package-templates.ts`: مخزن sessionStorage محدود خاص بالحساب والمقرر. العلامة تضم معرف العملية ونوعها ومعرف القالب عند معرفته ورقم المراجعة وعددي المراجع والوسائط المتوقعين فقط. لا اسم قالب أو درس أو مصدر أو اختيار أو محتوى أو رمز دخول. قراءة العلامة وكتابتها تتحققان من الحقول والـUUIDs وحدود النوع والعدد؛ create يبدأ بالنسخة 1، revise من 2، archive لا يخزن عدادات مراجعة.
- قبل أي POST/PATCH تُكتب العلامة. فشل الكتابة يمنع الطلب؛ تغير الجلسة قبل الإرسال يمنعه أيضًا. بعد إعادة التركيب تستعيد المكتبة العملية وتسمح باستعلام GET للإيصال فقط؛ لا تعيد كتابة ولا تحاول استنتاج فشل الحفظ من غياب الإيصال.
- الاسم والحصة والاختيارات والإصدار تُفحص محليًا قبل العلامة أصلًا؛ مدخل غير صالح لا يترك علامة عملية لم تُرسل، ولا تسمح الواجهة بتجاوز حد الإصدار الصحيح.
- الإيصال يتطابق مع العملية ونوعها والقالب والمراجعة والعدادات المحفوظة. الخادم الأصلي يثبت الحساب والمؤسسة والمقرر وسجل العملية؛ العلامة ليست سلطة. اسم القالب يُتحقق منه أثناء الجلسة الأصلية ويأتي من الإيصال المخول بعد إعادة الفتح، دون حفظه في العلامة.
- فشل تنظيف العلامة بعد نتيجة مؤكدة يبقي إيصال النجاح ظاهرًا ويقفل الكتابة والتصفح المتعارض حتى تسوية نفس العملية. فشل GET لا يحوّل النجاح المؤكد إلى فشل كتابة. رفض 4xx يحرر العملية فقط إذا نجح تنظيف العلامة؛ فشل التنظيف يبقي التسوية معلقة.
- القراءة الجديدة للقائمة صريحة. فشلها لا يمحو الإيصال أو يصف قائمة قديمة بأنها محدثة. إيصال الأرشفة له عبارة مستقلة؛ لا يُعرض كتأكيد إنشاء مراجعة. كل الإيصالات تاريخية، وليست دليلًا أن القالب ما زال بنفس حالته الآن.
- `LessonPackageTemplates.tsx` يركب المخزن الحقيقي، ويقف عند غياب التخزين، ويحتفظ بقفل النافذة الأم أثناء الكتابة أو التسوية. أُضيف اسم accessible لمنطقة المكتبة؛ التطبيق والجمهور والتوقيت والمخطط الخادمي لم تتغير سياساتها.

لا استرجاع عبر متصفح آخر أو بعد إنهاء جلسة sessionStorage، ولا حفظ محتوى محرر غير مرسل. العلامة المفقودة أو التالفة ليست تفويضًا لإعادة عملية مجهولة. المصنع يسمح بمخزن محقون للاختبارات؛ الواجهة الفعلية تمرر مخزن الجلسة وتفشل مغلقًا عند غيابه.
