# BUILD-48 — تحضير المدرس من مصدر الحصة إلى ملخص مراجعة مختار

دفعة J05 متكاملة على الديمو المعزول: ملخص مصادر الحصة، اختيار المجموعة والفترة، دليل الوسوم من نسخة الكويز المثبتة، ثم اختيار المدرس ونسخ ملخص محدود. ثُبت نقص الدليل وفقد المصدر وفشل سجل الإجابات؛ لا تشخيص تلقائي ولا نتيجة منشورة للأسرة.

## المنتج

- `src/features/catalog/lesson-learning.ts`: `learningBrief` يبني نصًا من **الوسوم التي اختارها المدرس صراحة**، مع المجموعة والفترة ووقت القراءة والعدادات. لا ينقل السؤال أو إجابته أو معرفه أو معرف الطالب/المصدر. لا ملخص دون اختيار أو مع دليل insufficient.
- نفس controller الحالي يملك النسخ الصريح مع single-flight، ومهلة عشر ثوانٍ، وفحص الحساب وعمر القراءة. تغير المجموعة/الفترة/الاختيار أو تحديث الأدلة يمحو إقرار النسخ القديم، وتغير الجلسة/التخلص يمنع عرض نجاح متأخر. فشل الحافظة لا يساوي نجاحًا ولا يمحو الدليل الصحيح. الطلب الذي وصل للحافظة لا يمكن إلغاؤه بأثر رجعي؛ الحماية لإقرار الواجهة والطلبات اللاحقة، وليست وعد محو حافظة الجهاز.
- `src/features/catalog/LessonLearningEvidence.tsx`: زر «نسخ ملخص التحضير» وحالات تأكيده داخل القراءة المخولة فقط. الأعداد تخص الإجابات والمحاولات المؤهلة، وليست كل طلاب المجموعة أو قياس الفهم. الاختيار ومسودة التحضير بذاكرة اللوحة؛ النسخ ليس حفظًا في النظام أو إرسالًا.
- `src/tests/lesson-learning-brief.test.ts`: سبعة اختبارات جديدة للخصوصية والاختيار والفشل والتزامن والمهلة والهوية والمصدر المتغير والتخلص. أُعيد استخدام ناقل وسياسات وقراء J05 الأصليين دون محرك تحليلات موازٍ أو تغيير قاعدة 5 محاولات/40٪.
