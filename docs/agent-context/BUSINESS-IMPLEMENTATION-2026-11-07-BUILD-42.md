# BUILD-42 — مساحة التصحيح بالسؤال للمالك

7 نوفمبر 2026. استمرار مباشر بطلب المالك، تنفيذ Codex. الجدولة وOpenCode
متوقفان. دفعة كود متكاملة محليًا، وليست انتهاء J08 أو قبولًا إنتاجيًا.

## النتيجة

لوحة فعلية مغلقة داخل صفحة التصحيح اليدوي لا تقرأ بيانات بمجرد فتحها. يختار
المالك امتحانًا ونسخة منشورة وسؤالًا مقاليًا، ثم يراجع عشر إجابات معلقة بلا
أسماء طلاب. تظهر صيغة السؤال ودرجته وشرحه المثبت؛ الشرح ليس معيارًا معتمدًا.
يكتب درجة كاملة بمنزلتين كحد أقصى وتعليقًا ثم يحفظ مراجعة، أو يستخدم
Ctrl/Cmd+Enter لنفس الإجراء. نوع الإجابة غير المدعوم لا يُفتح كرابط ولا يُصحح.

معاينة منفصلة تعيد قراءة اكتمال المحاولة ومجموعها. اعتمادها يحتاج مراجعة
حديثة وتأكيدًا صريحًا، ويستخدم محرك التصحيح وسجل الدرجات الحاليين، دون حساب
مكرر أو تعديل نسخة السؤال. حفظ السؤال ليس اعتماد المحاولة؛ الاعتماد لا ينشر
تقرير الأسرة. الربط بسجل الدرجات يُعرض وفق نتيجة المحرك الأصلية، بما فيها
حالة السماح الأصلية بتخطي الربط.

تزامن الإصدار يمنع الكتابة فوق مراجعة أخرى. المراجعة والتدقيق المختوم وإيصال
النتيجة في معاملة واحدة. فقد الرد يقفل الكتابة ويتيح GET فقط لاسترجاع النتيجة،
حتى بعد إعادة التحميل بعلامة محدودة بلا إجابة أو درجة أو تعليق أو token.
تعذر تخزين العلامة يمنع الطلب. فشل التحديث أو تنظيف العلامة لا يحوّل الحفظ
المؤكد إلى فشل؛ الصفحة القديمة تُخفى وتبقى الكتابة مقفلة عند فشل التنظيف.

## المعمارية والحدود

سلطة المالك الحي والمؤسسة وحالة الحساب وإصدار الجلسة والإيقاف تُثبت داخل
المعاملة؛ اسم الدور أو هوية الموظف لا يمنحان التصحيح. الطلبات والـDTO محددة،
والردود no-store. المحرك والمخزن والتدقيق المختوم الأصليون مستخدمون مباشرة.
التنقل والجلسة والمهل والردود المتأخرة محمية في واجهة المستخدم.

المراجعة الأولية للاعتماد تربط الإصدار والمجموع ومراجعات الأسئلة؛ تغيرها يرفض
الاعتماد. الإيصال التاريخي محصور بالمؤسسة والفاعل الأصلي مع إثبات مالك حي،
ولا يعني أن القائمة الحالية محدثة. الطلب المطابق بالمفتاح نفسه لا يكتب ثانية؛
اختلاف المحتوى يرفض. فشل إقرار commit يتلف الاتصال دون rollback لنتيجة مجهولة؛
قبل commit تتراجع المراجعة والتدقيق والإيصال معًا عند الخطأ.

بوابة المخطط تفحص ثمانية محركات معاملات، وحقول الإيصال وJSON ومعرفه المركب،
وفهرس قائمة المحاولات ومفاتيح تفرد الإجابات والمراجعات. حدود حزمة المحرك:
100 سؤال، 100 إجابة، 1000 مراجعة، مع كشف تجاوز محدود. عدم المخطط أو تجاوز
الحدود يرفض مغلقًا. ذلك لا يثبت كل أنواع الأعمدة أو قيود MySQL وخططه وأقفاله.
