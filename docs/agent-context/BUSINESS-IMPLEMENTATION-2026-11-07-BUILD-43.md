## ما أصبح يعمل فعليًا

### J08 — التصحيح بالسؤال

تطبيق اعتماديات الامتحانات الحديثة والمراجعات اليدوية والتدقيق المختوم وسجل
الدرجات وإيصالات BUILD-42 على MySQL **8.0.44** في قاعدة
`tabweb_demo_20261107162429`. لم يعد مسار التصحيح الجديد 503 لنقص مخططه.

اختبار HTTP مصادق مع MySQL حقيقي أثبت قراءة السؤال والإجابة دون أسماء، ورفض
مؤسسة أخرى 404 وطالب بلا مساحة مختارة 409 من middleware قبل الراوتر. طلبا
تصحيح متزامنان أعطيا 201 و409، مع مراجعة واحدة. إعادة العملية أعادت 200،
وتغيير محتواها رفض 409. GET استرجع الإيصال الدائم، ومعاينة المجموع أعطت
8.50 واعتمدته مع إسقاط واحد بسجل الدرجات وإيصالين. سلسلة التدقيق تحققّت.
EXPLAIN اختار فهرس القائمة على العينة الصغيرة؛ ليس اختبار حمل.

يوجد امتحان مستقل بعنوان **«تجربة التصحيح بالسؤال — جاهز للتجربة»** لحساب
المدرس المستقل `instructor` داخل `/manual-grading`. تجربة Chrome أدخلت
12abc فرفضته الواجهة دون POST، ثم حفظت مراجعة 6.00 بPOST واحد. هذه المحاولة
ما زالت pending_review ولم تعتمدها تجربة المتصفح، ويمكن مراجعتها. لا تُستخدم
البيانات المصطنعة كقياس تعليمي أو إعلان عن نشر نتيجة للأسرة.

### J10 — إعادة استخدام إعدادات مقرر لموسم

لم أنشئ سجل مواسم موازيًا: استخدمت `academic_periods` الموجودة. لوحة فعلية
في `/courses` تختار الفترة والمقرر المخول واسم المسودة وتأكيد حق إعادة
الاستخدام، ثم معاينة صريحة وتأكيد. إنشاء مسودة مستقلة يعيد الاسم والمادة
والوصف والصف النصي فقط، ويبدأ بصفر سعر وحالة draft. لا تُنسخ مجموعات أو
تسجيلات أو تقييمات أو أسعار قديمة أو اشتراكات أو صلاحيات أو جداول.

المالك الحالي والجلسة والمؤسسة والمصدر والفترة تُثبت على الخادم. المعاينة
مرتبطة بتفاصيل المصدر والفترة والفاعل والاسم الجديد؛ تغيرها يرفض. قيد فريد
يمنع نسخ المصدر لنفس الفترة بمفتاح عملية مختلف، والإيصال والتدقيق وإنشاء
المقرر في معاملة واحدة. فقد الرد يسمح GET فقط، حتى بعد إعادة تحميل الصفحة
بعلامة جلسة محدودة. المقرر القديم وتاريخه لا يُحدثان ولا يؤرشفان ضمن النسخ.

اختبار MySQL/HTTP أثبت أن طلبين متزامنين ينشئان مسودة واحدة، وأن المصدر
بقي مطابقًا قبل/بعد، والتسجيلات والمجموعات والدرجات المنسوخة أعدادها صفر.
اختبار Chrome نفذ اختيارًا ومعاينة وتأكيدًا حقيقيًا وأنشأ مسودة موسم 2028.
أُنشئت أيضًا مسودة 2027 للاختبار المتصل بالخادم. الفترات تجريبية.

**قوالب المحتوى والمواد لا تُنسخ حاليًا**؛ حقوق المصدر وربطه بالمقرر الجديد
لا يجوز اختزالها في نسخ معرفات مرتبطة بالمقرر القديم. أضيف سجل تجهيز مواسم
مخول بصفحات 25، يقرأ أسماء وتواريخ الفترات والمقرر الناتج وقت الإنشاء حتى
بعد إعادة فتح الصفحة. هذه حقائق تاريخية، لا ادعاء بالحالة الحالية للنشر أو
النشاط. القراءة مستقلة، وتُخفى عند تغير الجلسة أو تعذر إثباتها. J10 جزئية.
