# 22 — دمج استراتيجية البيزنس في خطة المنتج والتنفيذ

تاريخ الإدراج: **3 نوفمبر 2026**. اعتمد صاحب المنتج إعداد ودمج هذه الخطة في المحادثة. الحالة: **مدرج في التخطيط؛ لا تنفيذ كود أو تشغيل أو قبول ميزات بموجب هذه الوثيقة**. كل دفعة تنفيذ تُعرض وتُعتمد وفق [18](18-workflows-and-execution-approval-ar.md).

**تحديث التنفيذ المحلي — 3 نوفمبر 2026:** فوّض المالك لاحقًا بدء التنفيذ المحلي المتتابع. نُفذ تحسين إرشاد الاستيراد وتصحيح ترتيب الدروس ضمن نطاقهما، وسُجلت الأدلة والحدود في [سجل التنفيذ](agent-context/BUSINESS-IMPLEMENTATION-2026-11-03.md). هذا ليس اكتمال الاستراتيجية أو إذن تشغيل حي. المعتمد الآن: عدة محتويات لكل درس، وفصل تقدم الدروس الجديدة عن المحتوى القديم مؤقتًا مع توضيح الفرق. لا يتطلب العمل المحلي المأذون به إعادة تأكيد روتينية؛ القرارات المؤثرة غير المحسومة والإجراءات الخارجية لها بواباتها.

## 2. الشريحة وعرض البداية

الشريحة الأولى **للاختبار**: مدرس مستقل أو سنتر لديه مجموعات متكررة ومساعد، ويتعامل مع محتوى وواجبات ورسائل موزعة. استعداد هذه الشريحة للدفع وكونها أفضل شريحة فرضيتان للتحقق.

المشتري الأساسي هو صاحب المؤسسة أو المدرس المستقل. المستفيدون: المدرس والمساعد والطالب والأسرة. لا اشتراك جديد مفترض لكل طرف، ولا سوق يضع منافسين أمام طلاب المدرس.

عرض البداية: **تشغيل مجموعة واحدة بمساعدة محددة، وحصة قابلة لإعادة الاستخدام، وطلب خدمة واضح**. لاحقًا، بعد بوابات M6، يُكمل العرض بملخص الأسرة ومسار الرجوع من الغياب. هذه حزمة قيمة تُبنى عبر مراحلها؛ ليست مبررًا لتقديم وظائف M6 قبل اعتمادياتها أو لإعلان الحزمة كلها جاهزة بعد M2.

## 3. ما لا يتغير

- جميع الوظائف المطلوبة حاليًا تبقى في نطاقها؛ ترتيب التجارب ليس إسقاطًا لبقية المنتج.
- الأسعار والشرائح ودورة الـ30 يومًا والمدة الفعلية والتسوية ومهلة الـ96 ساعة والعد بالطالب الفريد وفق 19 لا تتغير.
- لا عمولة جديدة، ولا تقسيم لمحفظة السنتر، ولا تحويل النقد إلى available، ولا تقديم دائن الاشتراك كمال قابل للسحب.
- F1/F2 بوابتان ماليتان قائمتان؛ لا تتجاوزهما تجربة أو قالب أو تقرير أو طلب خدمة.
- حقوق المؤسسة وبياناتها ومحتواها لا تنتقل تلقائيًا مع خروج مدرس، ولا تتبادل المؤسسات بياناتها عبر أجندة الأسرة.
- OTP والمزودون والفحص والتخزين والبث والمخطط يحتاجون إثباتًا منفصلًا؛ لا نجاح محاكَى أو سلطة من العميل.
- لا بيانات خاصة أو payloads أو كلمات مرور في البحث أو التحليلات أو سجلات الدعم.
- لا تواصل مع عملاء أو استيراد حي أو تشغيل مزود أو نشر أو شراء أو Git بموجب إدراج الخطة.

## 5. الرحلات: المستفيد والمهام والقبول

### J00 — سجل الحقيقة وخط الأساس والقيمة

**المستفيد:** صاحب المنتج والمؤسسة وفريق التشغيل. **الأولوية:** أول عمل تخطيطي، ومستمر مع كل رحلة.

المهام: جرد المصدر والتركيب الفعلي واختباراته ومخططه ومزوده؛ تعريف مهمتين قابلتين للقياس؛ توثيق طريقة التشغيل الحالية وتكلفة الإعداد والدعم؛ تسجيل ما يتطلب قرارًا. لا يُعاد استخدام نتائج أكتوبر أو PDF كاختبارات جديدة.

القبول المستهدف: لكل ملاحظة مسار مصدر أو تجربة موصوفة وتاريخ وحدود. يُفرق بين ملف migration وتطبيقه، وبين factory وتركيبها، وبين اختبار محقون وتشغيل حقيقي. تُقاس المهمة حتى نتيجة صحيحة مع وقت جميع الأطراف. لا أحداث تحليلات تحمل PII أو إجابات أو إيصالات خامًا.

**المالك الوظيفي:** المنتج مع الهندسة والتشغيل، دون تعيين شخص أو افتراض توفر فريق جديد. **المراجع:** Q4/Q7/Q8 وBX-10.

### J01 — بدء مجموعة واحدة وانتقال منظم

**المستفيد:** صاحب المؤسسة والمساعد. **الأولوية:** أول رحلة تشغيل بعد الأساس. **التبعيات:** C1/C5/C8/C9/C10/C12 وS5/S10؛ تحقق اتصال أو تسجيل عند الحاجة وفق عقده، وتصدير Q6 حيث يلزم.

المهام: تحديد مجموعة واحدة وحدود البيانات؛ مطابقة حقول وتكرارات؛ معاينة ثم استيراد مخول؛ تقرير المرفوض والمقبول؛ إعداد الدور والمجموعة؛ تدريب مستخدم أساسي وآخر بديل. البدء ببيانات مصطنعة؛ الخدمة البشرية تُحدد بساعات ونطاق بعد الجرد.

القبول المستهدف: إعادة نفس commit لا تضاعف الاستيراد؛ نفس الهاتف لا يدمج طفلين؛ صف طالب لا ينشئ حسابًا أو تسجيلًا أو وصولًا أو دفعًا ضمنيًا. يستطيع البديل إكمال مهمة محددة، وتُسجل المساعدة اللازمة. لا كلمات مرور منافس ولا سحب غير مخول.

**قرار قبل التنفيذ:** أنواع الصادرات المدعومة وما لن يُنقل، وخطوات الحساب والتسجيل المنفصلة. **القياس:** زمن أول مهمة ناجحة وصحة عينة النقل وساعات الخدمة. **المالك الوظيفي:** التشغيل مع الهندسة. **الأفكار:** BX-01/BX-18.

### J02 — حزمة حصة وتحديث محتواها

**المستفيد:** المدرس والمساعد والطلاب. **التبعيات:** C5/C6/C7/C10، وV1/V3 للوسائط، وA1/A2/A5 للتقييم وفق نوع المحتوى.

المهام: حسم ربط الدرس بالمحتوى وصاحب تقدم الطالب؛ تعريف قالب يضم مراجع مواد وواجبًا وكويزًا وإعلانًا؛ اختيار المجموعات وتخصيص التوقيت؛ معاينة المستهدفين والنسخ؛ نشر وتاريخ تغيير. لا تُنسخ كل الكيانات في عملية غير واضحة ولا يبدأ نشر جماعي بلا معاينة.

القبول المستهدف: مرجع خارج tenant/course مرفوض؛ درس مقفول لا يسلم locator خاصًا؛ تحديث المادة يبين إصداره؛ استثناء مجموعة يبقى واضحًا؛ تغيير سؤال أصلي لا يغير نسخة امتحان ثابتة. التعديل المتزامن أو المرجع المؤرشف له تعارض مفهوم واختبارات رفض بلا كتابة.

**قرار المالك المحسوم في 3 نوفمبر 2026:** عدة محتويات لكل درس، وسجل catalog مستقل عن تقدم المحتوى القديم مؤقتًا. تبقى سلطة ربط كل نوع محتوى بمقرره ومسار تسليمه موضوع تحقق وعقد قبل البناء؛ وثيقة M2-B16 السابقة لا تعتمد كاملة ضمنيًا. **القياس:** وقت إعادة تجهيز الحصة وأخطاء التخصيص. **المالك:** المنتج/التعليم مع الهندسة. **الأفكار:** BX-05/BX-17.

### J03 — تجربة مناسبة وتسليم موثوق

تحديث تنفيذ محلي 6 نوفمبر 2026: [BUILD-20](agent-context/BUSINESS-IMPLEMENTATION-2026-11-06-BUILD-20.md) يربط جلسة الفيديو بمرجع الدرس صراحة، ويحفظ سياقها مع إنشائها ويعيد التحقق عند التجديد وتسليم الوسائط وheartbeat، ويمنع تجاوزه بجلسة عامة. واجهة الطالب ما زالت الخطوة التالية؛ المخطط غير مطبق ولا يوجد قبول مزود أو قياس حمل. هذه إضافة لرحلة جزئية وليست إغلاقًا لـJ03.

**المستفيد:** الطالب والأسرة والمدرس والدعم. **التبعيات:** C4/C10 وV2/V3/V5/V6، وA2/A5 للمحاولات، وQ4 للتشخيص.

المهام: عينة مخولة تستخدم نفس طريقة تشغيل المادة؛ إعلان أجهزة ومتصفحات مختبرة؛ طريق مختصر للمحتوى؛ تمييز حفظ محلي عن وصول خادمي وعن تسليم نهائي؛ مرجع استعلام عن نتيجة الطلب؛ شرح سبب القفل والإجراء المسموح.

القبول المستهدف: عينة الجهاز لا تفتح محتوى مدفوعًا؛ المنتهي أو المسحوب يفقد الوصول؛ فقد الرد بعد وصول تسليم لا ينشئ محاولة مضاعفة؛ الحفظ المحلي لا يظهر كتسليم خادمي؛ سياسة deadline مكتوبة وتُختبر قبل/عند/بعد الموعد؛ الدعم لا يرى إجابات أو بيانات زائدة. تجربة قبل الشراء لا تفعل checkout قبل F1/F2.

**قرارات حاجزة:** سياسة الاستكمال بعد انقطاع الاتصال، ومصفوفة الأجهزة، وإذن مادة العينة. **القياس:** نجاح التشغيل المدعوم وطلبات الدعم وفقد/تكرار التسليم المؤكد. **المالك:** التعليم والدعم والهندسة. **الأفكار:** BX-07/BX-15/BX-16.

### J04 — طلب خدمة يصل لمسؤوله

**المستفيد:** الطالب والمدرس والمساعد والإدارة. **التبعيات:** O5 وP6 للسؤال العلمي وS3/S10؛ P3–P5 فقط إن استُخدمت قنوات خارجية.

المهام: أنواع طلبات محدودة؛ ربط بسياق درس/محاولة/طلب نقل؛ توجيه حسب تكليف فعلي؛ حالة ومسؤول وخطوة لاحقة؛ تحويل بشري وتتبع التأخير. نعيد استخدام support/Q&A إذا طابقا العقد، ولا نبني صندوقًا موازيًا دون سبب.

القبول المستهدف: معرّف درس من العميل لا يمنح سلطة؛ المدرس يرى المكلّف به فقط؛ الهاتف أو الإيصال أو إجابات الامتحان لا تُرفق تلقائيًا؛ فصل ملاحظة الدعم الخاصة عن رد الطالب؛ إعادة المحاولة لا تنشئ طلبًا مكررًا. الطلب المالي إحالة لمسؤول مخول ولا يغير الرصيد.

**قرار حاجز:** تصنيف الطلبات وسلطة التحويل ووقت الاستجابة الواقعي. **القياس:** الرسائل لكل حل وإعادة الفتح ووقت المدرس. **المالك:** التشغيل والدعم مع الهندسة. **الفكرة:** BX-06.

### J05 — تحضير مختصر قبل الحصة

**المستفيد:** المدرس. **التبعيات:** بيانات A7/G7/P6 المتاحة فعليًا لكل مرحلة، والصلاحيات وQ4؛ لا التزام AI قبل إثبات الحاجة والتكلفة.

المهام: اختيار إشارات قليلة مع مرجعها؛ إظهار أكثر مفهومين يحتاجان مراجعة وفق قاعدة معلنة؛ أسئلة متكررة وحالات تتطلب انتباهًا؛ تمكين المدرس من الرفض والتصحيح. تُختبر فائدة ملخص يدوي/قواعد بسيطة قبل محرك توليد.

القبول المستهدف: التصفية حسب التكليف والمؤسسة؛ عدم وجود بيانات يظهر «لا يكفي الدليل»؛ كل بند يفتح دليلًا مخولًا؛ لا استنتاج كسل أو قدرة أو نية؛ لا تُعرض درجات غير منشورة لأسرة. اختبارات حد المجموعة/الفترة ومنع الرد القديم بعد تبديل السياق.

**القياس:** وقت التحضير وفائدة البنود التي استخدمها المدرس، لا عدد التنبيهات. **المالك:** التعليم/المنتج. **الفكرة:** BX-04.

### J06 — ملخص للأسرة وأجندة مخولة

**المستفيد:** ولي الأمر والطالب والمدرس. **التبعيات:** A7/G7/P1/P2/P3، وP4/P5/P7 عند الإرسال. موضع التشغيل الكامل M6.

المهام: ملخص ما تم وما يحتاج متابعة وخطوة واحدة؛ تفاصيل اختيارية؛ تواتر ووقت هادئ؛ أجندة الأبناء المرتبطين؛ معاينة المرسل والجمهور والمعلومات؛ حالة تسليم لا تتظاهر بوصول لم يحدث.

القبول المستهدف: علاقة مسحوبة أو طفل آخر يُرفضان؛ درجات غير منشورة لا تظهر؛ المؤسسة لا ترى مؤسسات الأسرة الأخرى؛ opt-out يوقف القناة؛ retry لا يكرر الرسالة؛ مزود أو مخطط أو جهة اتصال غير متحقق منها تبقى unconfigured. اختبار فهم ولي الأمر للمطلوب دون مقارنات أو لوم.

**قرارات حاجزة:** القنوات والتواتر ومعلومات الملخص، وتقبل تجميع الأسرة عبر المؤسسات، وسياسة الطفل بلا هاتف. **القياس:** فهم الأسرة والاستفسارات المتكررة وتكلفة الإرسال. **المالك:** المنتج/التشغيل. **الأفكار:** BX-02/BX-08.

### J07 — رجوع من الغياب ومراجعة موجهة

**المستفيد:** الطالب والمدرس والأسرة عند الربط. **التبعيات:** J02 وC6/C7/C10 وA7/G7؛ ربط السؤال بشرح وسائط يحتاج M3، والأسرة M6.

المهام: المدرس يحدد ما فات ومسار رجوع صغير؛ ربط مفهوم بسؤال وجزء من الشرح؛ تدريب تشخيصي وخطوة لاحقة؛ إظهار مصدر ومدة تقديرية معروفة، ومراجعة من يتعثر بدل التوصية الدائرية.

القبول المستهدف: خطة الرجوع لا تفك prerequisite أو تمد اشتراكًا؛ الغائب بعذر لا يُعاقب بتصنيف آلي؛ الروابط tenant/course scoped؛ لا مساواة بين وقت المشاهدة والفهم؛ مراجعة المدرس للربط؛ لا تسرب أسئلة امتحان نشط أو مفتاحه من التوصيات.

**قرار حاجز:** معيار الإكمال وحق المحتوى وآلية تدخل المدرس؛ لا تقدير أثر سببي من ارتباط فقط. **القياس:** بدء وإكمال الخطة والعودة للمشاركة، مع حالات متقاربة وحدود العينة. **المالك:** التعليم. **الأفكار:** BX-03/BX-13.

### J08 — تصحيح بالسؤال وإصلاح أثر الخطأ

**المستفيد:** المصحح والطالب والإدارة. **التبعيات:** A1/A2/A3/A4/A6/A7، والصلاحيات والتدقيق الذري؛ في M4.

المهام: عرض الإجابات حسب السؤال ومعياره؛ اختصارات وإخفاء اختياري للأسماء؛ تعليقات لإجابات مختارة؛ معاينة أثر تغيير مفتاح/سياسة؛ اعتماد سبب والتعامل مع التقارير المرتبطة. البداية بقرار تقييم بشري؛ توليد التصحيح قرار منفصل.

القبول المستهدف: المصحح يرى تعيينه فقط؛ key لا يصل للطالب أثناء المحاولة؛ نسخة الامتحان النشطة ثابتة؛ تصحيح نتيجة لاحق يتبع عقد revision منفصل يحفظ القديم والجديد؛ إعادة التشغيل لا تضاعف التعديل؛ فشل audit لا يترك تغييرًا؛ تغييرات مصححين متزامنة لا تضيع بصمت؛ الدرجة pending_review لا تعرض نهائية.

**قرارات حاجزة:** متى يسمح بإعادة التصحيح ومن يعتمدها؟ لا يغير ذلك استبعاد الشهادات. **القياس:** زمن النشر الصحيح واتساق عينة وتظلمات معاد فتحها. **المالك:** التعليم والهندسة. **الأفكار:** BX-12/BX-14.

### J09 — كنترول ورقي بالموبايل

**المستفيد:** المدرس وموظف الكنترول والطالب. **التبعيات:** J08 وA2/A3/A6/S6 وفحص الرفع واستعادة مهامه. **الأولوية:** توسع مشروط بإثبات أن العبء يستحق التكلفة، وليس شرط إغلاق سابق مفترض لكل M4.

المهام: تجربة دقة ببيانات مصطنعة لنموذج إجابة ثابت؛ ترقيم نماذج وربط ورقة؛ تصوير ومراجعة منخفض الثقة؛ كشف التكرار؛ اعتماد ونشر نتيجة وتدريب لاحق. تقاس ظروف الكاميرا والإضاءة والطباعة.

القبول المستهدف: لا نتيجة نهائية لورقة مجهولة أو قراءة ملتبسة؛ الورقة المكررة لا تنشئ درجات إضافية؛ ربط tenant/student/model يُثبت؛ عينة دقة يراجعها إنسان قبل التوسع؛ لا صور طلاب أو إجابات في logs، ولا ملف غير مفحوص يتحول إلى clean. لا وعد بقراءة أي خط يد.

**قرار حاجز:** نموذج الورقة وسياسة الخطأ المقبول وحجم العينة وملكية الصور ومدة الاحتفاظ ومزود/تقنية OMR إن لزم. **القياس:** زمن الدفعة ومعدل المراجعة والدقة وتكلفة المعالجة. **المالك:** التعليم والمنتج والهندسة. **الفكرة:** BX-11.

### J10 — موسم جديد مع تاريخ محفوظ

**المستفيد:** المؤسسة والمدرس والمساعد. **التبعيات:** C5/C8 وJ02، وA1/A2 عند إعادة استخدام أسئلة؛ لا رسوم أو تجديد تلقائي.

المهام: اختيار إعدادات وقوالب لإعادة الاستخدام؛ معاينة تقويم وتواريخ ومواد؛ تقرير ما تغير وما يحتاج تحديثًا؛ حفظ الموسم السابق. لا تُنسخ التسجيلات أو الأرصدة أو المدفوعات أو الصلاحيات.

القبول المستهدف: حدود المؤسسة والتكليف ثابتة؛ التواريخ الجديدة مراجعة لا ترحيل أعمى؛ نتيجة فشل/تكرار عملية النسخ واضحة ولا تترك مواد نصف منشورة؛ لا تغيير في تقارير الموسم السابق؛ لا وصول أو فاتورة تنشأ من النسخ.

**قرار حاجز:** تعريف الموسم وقائمة الحقول المسموح نسخها وحقوق المحتوى. **القياس:** وقت الإعداد وأخطاء التواريخ والحاجة للمساعدة. **المالك:** التعليم/التشغيل. **الفكرة:** BX-09.

## 7. قرارات قبل كتابة كود جديد

| القرار | لماذا يمنع افتراضًا صامتًا؟ | يوقف أي جزء؟ |
|---|---|---|
| ربط المحتوى وصاحب progression | حُسم تعدد المحتوى وفصل السجلين؛ تبقى سلطة المقرر والتسليم لكل نوع بعقد | تنفيذ الربط في J02 ينتظر الإثبات التقني، لا إعادة سؤال القرارين المحسومين |
| علاقة القالب بالمراجع والإصدارات | النسخ قد يغير امتحانًا أو يكشف مادة | نشر القالب وتحديثه J02 |
| deadline والاستكمال بعد الانقطاع | حفظ محلي ليس تسليمًا ولا تمديدًا | حالات التسليم J03 |
| القنوات والتواتر وربط الأسرة | جهة اتصال موجودة ليست إذن إرسال | إرسال J06؛ العرض المخول له عقده |
| تعريف الموسم وحقول النسخ | لا ترحيل مالي أو وصول ضمني | J10 |
| عقد التصحيح وإصلاح الأثر | لا تغيير نسخة امتحان نشطة أو تاريخ بصمت | إعادة التصحيح J08 |
| دقة وتكلفة الورق وفحص الصور | لا نجاح OMR أو clean محاكى | J09 |
| سعة التشغيل والدعم | لا وعد 24/7 أو حل فوري غير مدعوم | أي SLA أو خدمة إضافية مسعرة |

يمكن إنجاز جرد أو تصميم غير معتمد على قرار مفتوح، لكن الجزء التابع له ينتظر حسمه. لا تتطلب كتابة هذه الخطة إعادة الموافقة؛ التنفيذ اللاحق له دفعاته.

## 8. اقتصاديات التجربة ومعايير التوقف

نثبت خط الأساس ثم نحدد مع العميل، قبل التجربة المخولة، المهمة وحجم العينة والجهاز والاتصال وما يُعد نتيجة صحيحة. الحد الأدنى للتقرير: الوقت الكامل لكل طرف، الأخطاء وإعادة العمل، طلبات الدعم، ساعات الإعداد، والتكاليف المباشرة للمزود والتخزين والمعالجة والإرسال. لا تسجيل محتوى حساس لأجل القياس.

- نجاح الاستخدام: مستخدم بديل ينجز المهمة ومعه بيانات صحيحة وحالة خطأ مفهومة؛ حدود الوقت والدقة تُحدد بعد خط الأساس لا بأرقام تسويقية مخترعة.
- نجاح تجاري: استخدام متكرر واستعداد مناسب للدفع وتجديد عند إمكان قياسه، مع تكلفة خدمة يمكن تحملها. الاهتمام أو عدد الحسابات وحده لا يكفي.
- هامش المساهمة: الإيراد المعتمد للفترة ناقص التكاليف المباشرة. لا أسعار أو رسوم أو خصومات جديدة بهذه الوثيقة.
- توقف/إعادة تصميم: فقد تسليم مؤكد، تسرب أو توسع وصول، فرق مالي، نتائج غير قابلة للتفسير، فائدة غير ظاهرة، أو اعتماد دائم على خبير وتكلفة لا يمكن تغطيتها. العيب الأمني أو المالي حاجز؛ لا يستثنى لأن العينة صغيرة.
- لا تعميم نتائج عينة على مصر، ولا قصة عميل دون إذن، ولا ادعاء أثر دراسي سببي من ارتباط.

## 10. قالب إغلاق كل دفعة

1. الرحلة وBX والصفوف المقابلة في 17، والسلوك قبل/بعد.
2. ملفات المصدر والاختبار والتركيب التي قُرئت وما تغير فعلًا.
3. حالة authority/schema/provider/audit والقرارات المفتوحة.
4. دليل السلوك السليم والرفض والانقطاع والتكرار والتعارض بحسب المخاطر.
5. الأوامر والنتائج الحديثة وحدودها؛ لا إعادة تقديم أرقام تاريخية كإثبات جديد.
6. أثر العمل على الوقت والخطوات والتكلفة إن قيس؛ وإلا يكتب «لم يقس بعد».
7. الحالة: مخطط / عقد جاهز / منفذ محليًا / مقبول ضمن نطاق / ينتظر تشغيلًا مخولًا؛ لا Done من المستند وحده.
