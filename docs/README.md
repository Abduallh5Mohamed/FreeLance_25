# Tabweb Teachers — خطة المنتج والتنفيذ

**القرار الحاكم المحدث:** التسعير تدريجي للمدرس والسنتر؛ فوترة المؤسسة كل 30 يومًا مع حساب مدة فعلية بالثواني وتسوية، لا عمولة على الطلاب؛ محفظة السنتر وحده أو المدرس المستقل؛ خصم الاشتراك من المتاح ومهلة 4 أيام. المرجع [19 — القرارات المعتمدة](19-commercial-registration-wallet-agreement-ar.md)، والموافقة قبل التنفيذ في 18. الوثائق ليست دليل تشغيل.

**شرط التنفيذ الحاكم:** قبل كل دفعة تنفيذ يعرض المنفذ المهام والأثر والاختبارات والاستفسارات في المحادثة، وينتظر قرار المستخدم «نفّذ» أو «متنفّذش» أو تعديلات. لا تكفي موافقة سابقة على مرحلة كاملة. تفاصيل الموافقة ورحلات المستخدم في [18 — الرحلات والموافقة قبل التنفيذ](18-workflows-and-execution-approval-ar.md). لا يبدأ التنفيذ إذا بقي استفسار مؤثر دون حسم.

هذه خطة المنتج والهندسة الكاملة متعددة المستأجرين. المراحل M1–M8 ترتيب بناء واعتماد؛ لا تحذف وظائف من النطاق. يبدأ أي surface جديد بعد اجتياز security + tenant core. المستندات لا تثبت أن implementation الحالي مكتمل.

## جولات العمل

1. مسودات مستقلة لمجالات السوق والمدفوعات والنمو؛ المعمارية والفيديو والتقنية؛ الأمن والميزات وتجربة المستخدم والتنفيذ.
2. نقد متقاطع داخل أقسام الأدوار: كل مجال يختبر قرارات مجالين آخرين على الأقل.
3. حسم التعارضات في جداول `Decision / Alternatives rejected / Why` مع إبقاء الروابط بين الوثائق.
4. تقييم لكل ملف، وفرض بوابات إصلاح قبل اعتبار الخطة جاهزة للتنفيذ. الدرجات تخص جودة الخطة، ولا تعني أن المنتج الحالي اجتاز تدقيقًا أمنيًا.

## قواعد حاكمة

- المنتج يضم Super-Admin وTeacher/Center وStudent وParent وجميع الوظائف في `17`.
- الاشتراك الذاتي والعروض والمحفظة والتحصيل ضمن المنتج؛ أسعار اشتراك المنصة في 19، رسوم المزود وعمولة المنصة تحتاج اعتمادًا.
- شريحة SaaS وتهيئة VdoCipher موجودتان جزئيًا؛ راجع [خطة الشريحة الحالية](SAAS_SLICE_ROLLOUT_AR.md) و[إعداد DRM](web-drm-setup.md). هذه وثائق حالة تاريخية يجب تأكيدها على كل deployment.
- سجل التدقيق الأمني هو المرجع لتحديد المسارات والجداول الفعلية قبل أي ترحيل؛ انظر [تقرير التدقيق](ARCHITECTURE_AUDIT_AND_MIGRATION_PLAN_AR.md).

تقارير التدقيق الهندسي وتقارير الواجهة تحت `docs/` تحفظ كأدلة على الحالة وقت إعدادها؛ أي ذكر لنطاق تجريبي أو سلوك سابق فيها لا يغير نطاق المنتج الكامل في هذه الخطة.
