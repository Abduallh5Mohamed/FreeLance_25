# النمو وتجربة العميل

**القرار الحاكم المحدث:** التسعير تدريجي للمدرس والسنتر؛ فوترة المؤسسة كل 30 يومًا مع حساب مدة فعلية بالثواني وتسوية، لا عمولة على الطلاب؛ محفظة السنتر وحده أو المدرس المستقل؛ خصم الاشتراك من المتاح ومهلة 4 أيام. المرجع [19 — القرارات المعتمدة](19-commercial-registration-wallet-agreement-ar.md)، والموافقة قبل التنفيذ في 18. الوثائق ليست دليل تشغيل.

هذه خطة طلب وتبنٍ للمنتج الكامل، تدعم التسجيل الذاتي والاشتراك والفواتير والعروض الخاصة وفق 19؛ احتساب تسجيلات الطلاب الفعالة عند كل مدرس.

## الشريحة والقيمة

مدرسون ومراكز تعليمية لديهم مجموعات ومواد وامتحانات/حضور وجمهور أولياء أمور. القيمة المستهدفة: تشغيل التعليم والإدارة والتواصل من مكان واحد بعلامة المدرس، لا فيديو فقط ولا سوق مركزي.

## رحلة الاكتساب والاحتفاظ

1. جلسة فهم عمليات المدرس الحالية والمواد ومجموعة قنوات التواصل والمشكلات.
2. استيراد template مع معاينة البيانات، إعداد branding/domain، إنشاء مقرر وجلسة واختبار.
3. دعوة المدرس/المساعد والطلاب/الأولياء؛ قياس إكمال كل خطوة.
4. إدارة دورة كاملة: نشر، اختبار، حضور، تسليم واجب، تقرير ولي، وتصدير.
5. مراجعة استخدام ونجاح ومعالجة ticket؛ المؤسسة تراجع الفاتورة والتسوية وتدفع الفرق خلال 4 أيام عند نقص المحفظة؛ العروض الخاصة بإذن الإدارة.

## قنوات

علاقات مباشرة بالمدرسين، مجتمع المعلمين، شراكات مراكز وتدريب، إحالات مدرس-لمدرس بموافقة، محتوى عربي يشرح التدفق الفعلي. لا نشتري اكتسابًا واسعًا قبل ثبات onboarding والتكلفة والأمان والدعم.

## قياس ونموذج تشغيل

Activation = أول مقرر منشور + أول مجموعة + أول درس/اختبار أو فصل حسب الاستخدام. Retention = مدرس ينفذ نشاطًا تعليميًا وتشغيليًا متكررًا لكل فترة. راقب tenant onboarding duration، student enrollments، lesson completions، exam/assignment completion، attendance capture، parent link, notification opt-in, support resolution، وmetered usage. ربط المقاييس بالتعريفات وتصديرها؛ لا تعتبر المشاهدة وحدها نجاحًا.

## دعم

تذاكر مع severity/tenant/owner/status، help center، response target، onboarding session، incident escalation، وأدلة تشغيل. Impersonation للدعم فقط بوقت/سبب/صلاحيات ضيقة وbanner وتدقيق. راجع privacy/consent قبل WhatsApp/SMS.
